# ShitBoxTV 3.0 – Release-Kanal

Hier liegen nur die fertigen APKs (Releases) und `stable/version.json`, die die App für ihre Update-Anzeige liest.

ShitBoxTV 3.0 basiert auf **MKCinema von Dee Lavish** (https://github.com/itbelikethatbruh/mkcinema, GPL-3.0) und wurde verändert (umbenannt, Oberfläche in die App eingebaut, Server-Funktionen des Originals entfernt, NOS TV, Free TV, Wetter u. a. ergänzt).
Der Quellcode dieser Version ist auf Anfrage erhältlich (GPL-3.0, Abschnitt 6).
